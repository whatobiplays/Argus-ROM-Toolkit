# Frontend Specifications

Flutter frontend subsystem contracts belong here.

They define application structure, state architecture, client boundaries, routing, shell behavior, startup/recovery presentation, settings/theme workflows, design-system foundations, accessibility, and later feature-specific frontend contracts.

**Identifier format:** `SPEC-FE-NNN`
