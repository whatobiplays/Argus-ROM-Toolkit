# Reference Documents

Reference documents contain canonical vocabulary, registries, and taxonomies used by multiple specifications.

**Identifier format:** `REF-<AREA>-NNN`

Examples:

- platform registry
- artwork taxonomy
- event catalog
- error catalog
- command/job catalog
- provider capabilities
- hash-scheme registry

Other documents link to reference documents rather than redefining their contents.

Use [the reference template](../templates/reference.md).
