# Phase Specifications

Phase documents define capability sequencing: what user-visible outcome is built next, what it depends on, what is excluded, and how completion is measured.

**Identifier format:** `PHASE-NNN`

A phase may move to **Ready for Implementation** only after the readiness checklist in ARCH-002 passes and Daniel accepts the scope.

Phase documents must include ordered implementation slices, but they must not contain file-by-file Codex task instructions.

Use [the phase template](../templates/phase.md).
