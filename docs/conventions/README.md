# Engineering Conventions

Convention documents define repeatable rules for contributors and implementation agents.

**Identifier format:** `CONV-<AREA>-NNN`

Planned areas include:

- repository layout
- Rust
- Flutter/Dart
- naming
- errors
- logging and diagnostics
- testing
- generated files
- documentation
- code review and Codex handoff

A convention must be enforceable through tooling, tests, or review wherever practical.

Use [the convention template](../templates/convention.md).
